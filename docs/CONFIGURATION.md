# OmniTerm Configuration Guide

## 1. Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + Shift + T` | Open New Terminal Tab |
| `Ctrl + Shift + W` | Close Current Tab |
| `Ctrl + Shift + F` | Search within Terminal Buffer |
| `Ctrl + Tab` | Switch to Next Tab |
| `Ctrl + Shift + Tab` | Switch to Previous Tab |
| `Ctrl + Shift + C` | Copy Selected Text |
| `Ctrl + Shift + V` | Paste from Clipboard |

---

## 2. Terminal Appearance & Preferences
- **Font Family:** `JetBrains Mono`, `Fira Code`, `Cascadia Code`, `Consolas`, `monospace`.
- **Default Font Size:** 13px (configurable).
- **Themes:** Omni Dark (default), Bento Dark, Monokai, Dracula, Solarized.
- **Scrollback Buffer:** 5,000 lines (default).
